# Tutorials · updated 4 November 2026

The current retail workshop has its own four-step tutorial. Open **Retail studio →
How to use**, or **Sources & methods → Tutorials & walkthroughs → Open workshop
tutorial**. Each step can jump to the real retailer, shelf plan, product controls
or save menu. It does not replace the user's saved assortment.

**Save & download** separates an editable aisle backup (.json), a shareable
picture (.png), an assortment spreadsheet (.csv), and an optional Blender scene
(.glb). The menu explains phone downloads, moving a plan to another device,
Blender's File → Import flow, Material Preview, and saving a .blend file. The
command-line helper is inside a separate advanced disclosure. Opening a saved
aisle returns to the workshop with Undo available.

The existing 1920×1080 narrated catalog MP4 was recorded on **2 November 2026**
and lasts approximately **3m05s**, with nine chapters. It covers catalog browsing,
retail chains, character filtering, source details, comparison, catalog downloads,
weekly/trend evidence, sound and partial listings. The page labels it as a dated
catalog tour and directs current workshop questions to the guide above. The MP4
was not re-recorded for this tutorial update. Captions use proportional sentence
timings within each chapter.

The video is a dated example, not a live data feed or a completeness certificate. CSV exports contain absolute image URLs; they cannot embed images. The photo sheet displays linked photos and needs internet for images. Source check dates, currencies, markets and pack/variant basis remain in exports.

The root tutorial_build.py records an earlier interface. Do not use it to overwrite this video without updating its scenes and actions to the current interface. For another video revision, capture the current controls and regenerate matching narration, captions, chapters and poster. Keep MP4 video/audio decoding and browser playback checks. Count changes alone do not require a new tutorial.
