小狗陪你学英语

从「你好」开始，一次学一个短表达。小狗用中文解释，用慢速英语示范，再等你跟着说。答错了会示范改好的句子，不用着急。

二十门课程，每门五十题，共一千道练习。每年学习十个表达，用跟读、看中文说英语、听力选择、填空和回忆五种方式练习。内容从零基础逐渐走向复杂表达。这是有示范答案的引导式练习，不是无限话题聊天，也不会给发音打分。

小狗的声音由 AI 生成，打招呼、鼓励和庆祝各有不同情绪。可以选择公狗或母狗的声音。小狗会眨眼、动耳朵、摇尾巴、坐下、趴下和跳跃，也可以摸摸它。这是动画角色，不是实时拍摄。点名字旁的「改名」可随时换名字，也可以在设置里修改。改名后，下次点开始，小狗会先用新名字打招呼。

点一次「开始学英语」并允许麦克风后，可以连续跟读。小狗说话时，麦克风暂停，避免听到自己的声音。点「暂停」、切换到后台或长时间不说话会暂停练习。连接语音服务后，英语跟读和中文求助都能听。

每题首次答对得一根骨头，每年五十题全部完成后长大一岁并得到一百奖励币。骨头、课程进度、奖励币与已购装扮保存在你的账号中。重复练习不重复领奖。名字、性别、声音与中文释义设置保存在这台设备上。连接服务后，你每次回答的短录音会发送给 OpenAI 转写，使用你已连接的 API 账户；Pawlish 不保存你的录音。新名字会通过已连接的 OpenAI 账户生成一句自我介绍，保存后可重复播放。尚未连接时使用浏览器的语音识别。
