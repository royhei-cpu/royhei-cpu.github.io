# Pawlish on GitHub Pages

Public entry: https://royhei-cpu.github.io/pawlish/

This folder contains the actual lesson page and connection page. The Pages workflow copies all audio and dog assets locally with SHA-256 verification. Learners do not need a ChatGPT account. An unguessable browser visitor token identifies their own server-side progress, wardrobe, encrypted API connection and private avatar. It is not an OpenAI API key. Clearing browser storage starts a separate profile. Existing ChatGPT-account progress stays on the original site.

Voice recognition, new-name speech and avatar generation call the public visitor API at https://pawlish-ryans-english-dog.lhei111.chatgpt.site/api/public/. Each visitor must connect their own OpenAI account for paid requests; no owner or shared key is used. The original server must remain available. The interface and recorded lesson audio are hosted on GitHub Pages.
