# Current Homecare website guide

Player: https://royhei-cpu.github.io/home-care/tutorial.html

Release `20261104-workshop-a1` replaces the old catalog-and-Excel-only tutorial. It covers the current navigation (Opportunities last), global/China filters, shortlist comparison and CSV export, sales evidence, the White Label Workshop, national-brand photographs, suggested changes, dimensions, finishes, cost assumptions, development packs, configured briefs and sound settings.

The published guide is a captioned illustrated video, about 3 minutes, using real recorded retailer photos and actual A0/A1 Blender renders. It is explicitly labeled as an illustrated feature guide, not a screen recording. The browser's admin security-policy check did not permit a live capture; no alternative browser capture was used. A HeyGen narration request was rejected with a non-retryable 429 because the 30-day preview-voice quota was exhausted. No additional narration generation or alternate voice was run. A built-in English voice remains an optional user-approved follow-up; `voice: none` is explicit in the release manifest.

`guide-scenes.json` owns the script, semantic scenes, source interface commit and exact navigation. `render_guide.py` draws the guide using Pillow and renders H.264/yuv420p at 1920 × 1080 and 24 fps through FFmpeg. It takes `--work <output-directory>` and either `--visuals-only` or `--voice none`. The optional `--voice Samantha` path uses macOS speech at a fixed natural delivery rate and must only be used after approval of the voice fallback. It derives caption intervals from actual utterance lengths at 48 kHz and preserves delivery at 1.0×. The captions-only path uses explicit reading holds at 17.5 characters per second, rather than claiming alignment to nonexistent speech.

Rendering dependencies: Python 3, Pillow, NumPy (optional for future audio/graphics), and `imageio-ffmpeg` when `ffmpeg` is absent from PATH. Font defaults use macOS Arial and Georgia; `--fonts-dir` accepts a directory containing those font files on another workstation. Original photos retain their appearance and source provenance in `reference-images/sources.json` and the website's workshop-reference-evidence manifest. They are not generated website screenshots.

`package_guide.py --work <output-directory>` packages a completed render, timeline, WebVTT, poster, source receipt and chapter-linked player. The current MP4 is stored in verified base64 transport chunks. `assemble.py` checks byte length and SHA-256, then writes the current filename and both legacy video/download aliases. The Pages workflow assembles it before copying the Homecare site, so existing saved MP4 links also receive the replacement. Optional `--site-dir` permits isolated assembly tests.

The player has seekable chapters, direct website-section links, burned-in captions, a VTT download and the complete written guide. It does not also display a second caption track on top of the burned-in text. `guide.test.mjs` verifies transport integrity, all four output aliases, script/caption/timeline agreement, chapter seeking and the current navigation. Source hashes make later interface edits require a tutorial review, preventing silent drift. Keep the guide, timeline, chunks, manifest, captions and page updated together.

QA: the complete captioned encode was decoded; representative encoded frames and the source illustrations were inspected. No audio-listening claim applies to this captions-only release. Live browser/player appearance remains unverified while browser access is blocked. Run `node --test home-care/tutorial-media/guide.test.mjs` plus the existing Homecare suite before publishing.

A1 refresh: direct photo-first workshop links, five laundry-sorter render views, frame-only finish changes, reference photos in the download pack, and the distinction between A1 visualization and unchanged A0 engineering targets are covered.
